## Shape disclosure (read before citing this instance anywhere)

**This is a SAME-SHAPE sibling of `agent-audit-consulting`** — identical value→capture
loop (email intake → manual invoice → async written deliverable), content-parameterized
to requirements coverage instead of agent auditing. Per the `factory/SPEC.md` amendment
discipline and the `pitch-deck-review` precedent, **it does NOT discharge the factory's
n≥2 structural-generalization gate**, and `factory/specs/` is deliberately untouched.
What it CAN do: close the first real value→capture loop (warm-channel advantage the
first instance lacked).

## The one design decision that is not boilerplate

The refund condition is the method's own pre-registration bar: the client freezes their
expected-gaps list at intake, and the fee is owed only if the sweep surfaces gaps
beyond it. Selling the method and applying the method are the same act.
